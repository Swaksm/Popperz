# Installer Popperz

Popperz n'est pas (encore) sur les stores. On l'installe à la main, en deux minutes.

## Chrome, Edge, Brave

1. Télécharge `popperz-<version>-chrome.zip` et décompresse-le dans un dossier que tu garderas (par exemple `Documents/Popperz`). Ne supprime pas ce dossier : le navigateur charge l'extension depuis lui.
2. Ouvre `chrome://extensions` (Edge : `edge://extensions`, Brave : `brave://extensions`).
3. Active le **Mode développeur** (interrupteur en haut à droite).
4. Clique sur **Charger l'extension non empaquetée** et choisis le dossier décompressé.
5. Épingle Popperz : icône puzzle de la barre d'outils, puis la punaise à côté de Popperz.

Chrome peut afficher au démarrage un message sur les extensions en mode développeur. C'est normal pour une extension installée hors du Chrome Web Store : clique sur « Conserver » ou ferme le message.

## Opera GX

1. Télécharge et décompresse le zip, comme ci-dessus.
2. Ouvre `opera://extensions`.
3. Active le **Mode développeur** (en haut à droite).
4. Clique sur **Charger l'extension non empaquetée** et choisis le dossier décompressé.

## Mettre à jour

Il n'y a pas de mise à jour automatique. Pour passer à une nouvelle version :

1. Télécharge le nouveau zip et décompresse-le **dans le même dossier**, en remplaçant les fichiers.
2. Sur la page des extensions, clique sur la flèche de rechargement de Popperz.

Tes réglages (sites désactivés, éléments zappés) sont conservés.

# Installing Popperz

Popperz is not on the extension stores (yet). Installing it by hand takes two minutes.

## Chrome, Edge, Brave

1. Download `popperz-<version>-chrome.zip` and unzip it into a folder you will keep (for example `Documents/Popperz`). Don't delete that folder: the browser loads the extension from it.
2. Open `chrome://extensions` (Edge: `edge://extensions`, Brave: `brave://extensions`).
3. Turn on **Developer mode** (top right toggle).
4. Click **Load unpacked** and pick the unzipped folder.
5. Pin Popperz: puzzle icon in the toolbar, then the pin next to Popperz.

Chrome may show a warning about developer mode extensions at startup. That is expected for an extension installed outside the Chrome Web Store: click "Keep" or close it.

## Opera GX

1. Download and unzip, as above.
2. Open `opera://extensions`.
3. Turn on **Developer mode** (top right).
4. Click **Load unpacked** and pick the unzipped folder.

## Updating

There are no automatic updates. To move to a new version:

1. Download the new zip and unzip it **into the same folder**, replacing the files.
2. On the extensions page, click the reload arrow on Popperz.

Your settings (disabled sites, zapped elements) are kept.
